# OpenCOD

**OpenCOD — The Open Cause-of-Death Database** is an interactive resource for
exploring harmonised mortality and population statistics assembled from
official national sources.

## Access the website

### [Open the OpenCOD interactive dashboard](https://anfesanz.github.io/OpenCOD/)

OpenCOD was launched as a pilot in Latin America and is open to countries
worldwide. It preserves the documented sources, methods, and caveats associated
with each dataset.

## What you can explore

- mortality coverage by country and year
- deaths by age, sex, cause of death, and geographic area
- yearly mortality trends and cause composition
- data availability across demographic and geographic dimensions
- official national mortality and population sources

Country datasets can be downloaded free of charge after registration. Please
review and cite the original national sources alongside OpenCOD.

## Source code

The dashboard is mirrored from the
[LAMICOD repository](https://github.com/Mortality-Inequalities-Research-Group/LAMICOD),
which contains the reproducible data pipelines and the canonical website source.
